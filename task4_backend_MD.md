# Task 4: Backend API + Database

## 1. Project Description
Ye ek Notes App hai. Flask se Backend banaya hai aur data `notes.txt` file mein save hota hai.

## 2. Features
- **Add Note**: Website se naya note add kar sakte hain
- **Delete Note**: Har note ke saath Delete ka button hai
- **File Database**: Saara data `notes.txt` mein save rehta hai
- **REST API**: `http://127.0.0.1:5001/api/notes` pe JSON data milta hai

## 3. Technologies Used
- Python
- Flask
- HTML
- File as Database

## 4. How to Run
1.  Terminal mein `python app.py` likho
2.  Browser mein jao: `http://127.0.0.1:5001/`
3.  API check karo: `http://127.0.0.1:5001/api/notes`
